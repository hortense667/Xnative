Google Sheets → JSON 変換ツール

Google Sheets 上の4つのシート（events / genres / eraSettings / metadata）から JSON を生成してローカルに保存します。 シートは公開またはリンク共有でアクセス可能である必要があります。
Google Apps Script の Web App URL。CORS 問題を回避できます。空欄の場合は直接取得を試みます（CORS エラーになる可能性があります）。
全体のスプレッドシートURL（/d/〜/edit の形式）を貼り付けてください。
空の場合は nativemap_data.json になります。
シートの列仕様（TSVヘッダ）は以下の前提です。
eventslabel / label_en / startYear / endYear / genre / imp / url / url_en / note / note_en
genrescode / label / label_en / conjunction
eraSettingsname / startYear / endYear / color / opacity / enabled / fillEnabled
metadatatitle_ja / title_en / description_ja / description_en / initialCreator / contributors / contact_admin_* / createdAt / version / language / copyright / license / licenseUrl / notes
仕様: GAS API URL を指定した場合は、GAS 経由で JSON を直接取得します（推奨）。GAS API URL が空の場合は、Google Sheets の URL からスプレッドシートIDを抽出し、各シートを TSV として取得してから JSON 構造（events / genres / eraSettings / metadata）に組み立てます（CORS エラーになる可能性があります）。
