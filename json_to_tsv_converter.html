JSON → TSV 変換ツール

ローカルで動作します。ファイルを選択またはドロップして、4つのTSV（events / genres / eraSettings / metadata）を書き出します。
ここに JSON ファイルをドラッグ＆ドロップしてもOK
ファイル未選択
eventslabel / label_en / startYear / endYear / genre / imp / url / url_en / note / note_en
genrescode / label / label_en / conjunction
eraSettingsname / startYear / endYear / color / opacity / enabled / fillEnabled
metadatatitle_ja / title_en / description_ja / description_en / initialCreator / contributors / contact_admin_* / createdAt / version / language / copyright / license / licenseUrl / notes
入力ファイル出力（ダウンロード）
